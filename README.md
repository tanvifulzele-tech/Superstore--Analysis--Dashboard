# 📊 Superstore--Analysis--Dashboard
Superstore sales analysis and interactive dashboard using Microsoft Excel

## 📌 Project Overview

This Projetcs involves cleaning raw sales data, performing exploratory data analysis, calculating keys performance indicators(KPIs), and developing an interactive dashboard to generate actionable business insights.

## 📊 Dashboard Preview

## 🎯 Project Workflow

1. 🧹 Data Cleaning
 - cleaned and prepared raw sales data.
 - checked for duplicates records and missing values.
 - standardized data formats where requried.

2. 🔍 Data Analysis
 - Analyzed sales and profit performance.
 - Evaluated product, category and regional performance.
 - Identified sales trends and business patterns.

3. 📈 Keys performance indicators(KPIs)
 - 💰 Total saless
 - 👥 Total orders
 - 📊 Average sales of orders
 - 🛒 Total customers

4. 📊 Dashboard development
 - Created an interactive Excel dashboard.
 - Used KPIs cards and charts to summarize business performance.
   
## 🛠️ Tools Used & Skills

- Microsoft Excel
- Data cleaning
- Data analysis
- Pivot Table and Pivot Charts
- Slicers
- KPIs
- Data visualization
- Dashboard development

## 🎯 Project Objective

To transform raw superstore sales data into a meaningful business insights through data cleaning, KPI analysis, and interactive dashboard visualization.
